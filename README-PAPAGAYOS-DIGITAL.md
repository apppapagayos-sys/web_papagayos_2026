# Papagayos Digital — prototipo

Este prototipo adapta la portada de la web anterior al enfoque del Proyecto ALVEX.

## Publicar con GitHub Pages
1. Subí el contenido de esta carpeta al repositorio nuevo.
2. Confirmá que `index.html` esté en la raíz del repositorio.
3. Abrí Settings → Pages.
4. En Build and deployment, elegí Deploy from a branch.
5. Seleccioná `main` y `/(root)` y guardá.

## Incluye
- Portada responsive y navegación móvil.
- Secciones de experiencias, servicios y agenda.
- Mapa Leaflet con filtros por categoría.
- Asistente local de respuestas predefinidas.
- Contactos sociales existentes y acceso a WhatsApp.
- Enlaces a Historia, Paranormal/Leyendas y Créditos conservados desde el sitio original.

## Pendiente antes de considerarlo sitio oficial
- Verificar coordenadas y categorías de todos los marcadores.
- Incorporar y validar prestadores, horarios, teléfonos y contactos oficiales de emergencia.
- Confirmar que los enlaces y datos de contacto sean los correctos y estén autorizados.
- Conectar backend real si se requiere gestión dinámica de datos, analítica de QR o recepción de formularios.
- Probar visualmente en distintos celulares y navegadores.

Este es un prototipo estático. El asistente responde con reglas locales; no usa IA ni datos en tiempo real.
